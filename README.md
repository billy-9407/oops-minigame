# OOPS 포니 탈출 작전

포니 쿠페를 운전하여 보급상자를 파밍하고 AI 사격수를 피해 탈출하는 2분 생존 미니게임입니다. 좀보이드 같은 작은 캐릭터와 등각 시점을 사용한 독자적인 간단한 2.5D 그래픽입니다. 실제 PUBG 또는 프로젝트 좀보이드의 게임 리소스를 추출해 사용하지 않았습니다.

**첫 배포는 관리자 전용 테스트입니다. 사용자의 공개 요청 전에는 일반 이용자에게 열지 마세요.**

## 게임 방법

- PC: 마우스 좌클릭으로 목적지 지정. 누른 채 움직이면 계속 조향합니다.
- 모바일: 터치로 목적지 지정. 누른 채 드래그하면 조향합니다. 가로·세로 모두 지원합니다.
- 상자 근처에서 멈추면 1.4초 후 자동 파밍합니다. 별도 키보드나 우클릭은 필요하지 않습니다.
- 정지 버튼도 클릭·터치로 누릅니다. 차는 가속·감속하고 회전 속도에 제한이 있습니다.
- 주행 1m당 1점, 보급상자당 750점, 파밍 시 내구도 +10.
- AI가 차량을 향해 사격합니다. 총격·충돌·자기장 피해를 피하세요.
- 마지막 20초에 지도 좌상단의 초록 연막 탈출 지점이 열립니다. 그 안에서 2초 정차하면 탈출 성공, 1,500점 추가 후 게임이 종료됩니다.
- 최대 2분입니다. 내구도가 0이 되면 일찍 종료합니다. 탈출 실패 시에도 모은 점수를 기록합니다.
- 개인 최고점과 최근 최고 기록 10개는 브라우저에 저장합니다. 기기·브라우저를 바꾸거나 데이터를 삭제하면 개인 기록은 이어지지 않습니다.
- 실시간 멀티플레이가 아니라 각자 플레이하며 기록을 경쟁합니다.

## 기존 GitHub·Vercel 교체

대상 저장소: `billy-9407/oops-minigame` / 기존 주소: `https://oops-minigame.vercel.app/`

기존 프로젝트와 주소는 그대로 사용합니다. 기존 게임 파일을 모두 새 프로젝트로 교체합니다. 기존 저장소의 `api/get-code.js`, 루트 `index.html`, 그리고 **이름 앞에 보이지 않는 문자가 들어간 기존 public 폴더**를 제거하세요. 새 폴더 이름은 정상적인 영문 `public`입니다. Git 변경 내역은 남겨서 이전 버전으로 복구할 수 있게 합니다.

1. 저장소 루트에 이 프로젝트의 `package.json`, `build.mjs`, `vercel.json`, `lib/`, `api/`, `public/` 등을 넣습니다. ZIP의 상위 폴더를 통째로 넣어 루트가 한 단계 깊어지지 않도록 주의하세요.
2. Vercel 프로젝트 Settings에서 Framework Preset은 `Other`, Root Directory는 저장소 루트로 둡니다. 기존 사용자 지정 경로가 있으면 새 루트에 맞게 바꾸세요.
3. Build Command는 `npm run build`, Output Directory는 `public`입니다. `vercel.json`에 지정되어 있습니다.
4. Vercel 환경 변수 `GAME_SECRET_KEY`는 기존 디스호스트와 같은 32자 이상 키로 유지합니다. 브라우저에 공개되는 환경 변수로 만들지 마세요.
5. Vercel 환경 변수 `GAME_ACCESS=admin`을 설정합니다. 값이 없더라도 관리자 전용으로 닫힙니다.
6. main에 반영되면 기존에 연결된 Vercel이 자동 배포합니다. Ready 상태와 웹사이트 점검 화면을 확인하세요. GitHub 연결을 끊는 것은 이미 배포된 게임을 막는 방법이 아닙니다.

## 수송기봇 교체와 관리자 테스트

별도로 전달한 `app.py`는 디스호스트에서 사용합니다. **봇의 app.py, .env, voice_data.db는 공개 GitHub에 올리지 마세요.** 게임 저장소에는 봇 변경만 적용하는 `bot/apply_pony_patch.py`를 제공합니다.

1. 기존 `voice_data.db`를 그대로 유지하고 디스호스트의 app.py만 새 파일로 바꿉니다. 기존 봇을 종료한 후 새 봇을 시작합니다.
2. 디스호스트 간편 설정 또는 .env에 `MINIGAME_ACCESS=admin`을 설정하세요. 값이 없어도 관리자 전용 테스트입니다.
3. 서버 소유자·마스터·운영진이 관리자전용 또는 저스트채팅에서 `!미니게임`을 입력합니다. 일반 PUBG 역할만 가진 이용자에게는 테스트 링크를 발급하지 않습니다.
4. 봇이 관리자용 서명을 붙인 개인 DM 링크를 보냅니다. 해당 링크로 접속하면 게임을 할 수 있습니다. 일반 주소, 일반용 링크, 기존 게임 링크는 관리자 테스트 중 사용할 수 없습니다.
5. 관리자 테스트에서는 보상 코드를 발급하지 않으며, `!보상`도 지급을 거절합니다. 일일 보상 횟수는 소모되지 않고 공용 기록도 오염시키지 않습니다.
6. 링크는 2시간 유효합니다. 테스트 링크는 접속 권한 자체이므로 다른 이용자에게 전달하지 마세요.

관리자 테스트는 별도 Vercel 계정 가입을 요구하지 않습니다. 기존 주소에서 관리자 개인 링크만 통과시키는 방식입니다.

## 정식 공개: 사용자 요청 이후에만

1. Vercel 환경 변수 `GAME_ACCESS=public`으로 변경하고 다시 배포합니다.
2. 디스호스트 `MINIGAME_ACCESS=public`으로 변경하고 봇을 다시 시작합니다.
3. 이후 `!미니게임`으로 새 일반용 개인 링크를 받으세요. 관리자 테스트용 링크는 공개 후에도 계속 테스트로 취급되어 코인이 지급되지 않습니다.

두 설정을 함께 바꾸는 이유는 사이트의 접속 제한과 봇의 명령어·지급 제한을 각각 제어하기 때문입니다. 같은 환경에서 관리자 테스트로 되돌리려면 둘 다 `admin`으로 설정하세요.

## 코인 지급

- 무제한 플레이, 한국 시간 기준 하루 한 번 지급.
- 최종 점수 1,000점당 1코인, 소수점 버림, 최대 10코인. 1,000점 미만은 지급하지 않습니다.
- 점수는 주행+상자+탈출 보너스입니다. 탈출 성공만 지급 조건으로 제한하지는 않았습니다.
- 게임 종료 화면에서 `!보상 [코드]` 전체를 복사하여 저스트채팅에 붙여넣으세요. 기존 명령어를 유지합니다.
- 보상 코드는 본인 Discord ID에 연결됩니다. 발급일의 한국 시간 자정 전, 발급 후 2시간 이내 사용하세요. 자정을 넘겨 플레이했다면 실제 발급된 날 기준입니다.
- 같은 날 이전 미니게임에서 받은 보상도 유지합니다. 게임 교체로 보상 횟수가 초기화되지 않습니다.
- 기존 OOPS2 코드는 더 이상 인정하지 않습니다. 새 코드 형식은 OOPS3이며 지급액은 1~10코인입니다.
- 서버는 브라우저가 제출한 점수를 사용하지 않습니다. 서명된 시작 시드와 조작 기록을 같은 엔진으로 재현하여 주행·파밍·피해·탈출·경과 시간을 계산합니다.
- 빠른 제출·위조 링크·위조 세션·잘못된 조작 기록을 거절하며, 봇 SQLite 트랜잭션이 중복 지급을 방지합니다.
- 자동 조작·매크로까지 완전히 막는 기능은 아닙니다. 정상 조작을 자동 생성하는 공격에는 별도의 탐지나 제한이 필요합니다.

## 공용 서버 TOP 10

여러 기기의 기록을 영구 저장하려면 Vercel Marketplace에서 Upstash Redis를 연결하고 다음 환경 변수를 설정하세요.

```
UPSTASH_REDIS_REST_URL=발급된 HTTPS 주소
UPSTASH_REDIS_REST_TOKEN=발급된 토큰
```

연결한 뒤 다시 배포하면 Discord 개인 링크로 플레이한 이용자의 최고 점수만 서버에 저장합니다. 기록 이름은 `드라이버 ABCD` 같은 Discord ID 기반 가명입니다. 실제 Discord ID는 기록판에 공개하지 않습니다. 테스트·자유 플레이 기록은 공용 기록판에 올리지 않습니다. Redis를 연결하지 않아도 게임·개인 최고점·코인 지급은 작동하며, 공용 기록판에 연결 안내를 표시합니다. Redis 장애가 있어도 유효한 보상 코드는 발급합니다.

## 개발·검증

Node.js 22 이상 권장, 외부 npm 패키지 필요 없음.

```
npm run build
npm run dev
npm test
python tests/bot_rewards.py
```

로컬 .env는 .env.example을 참고해 만드세요. 테스트용 비밀키는 실제 운영 키와 다르게 쓰세요. 기본 개발 서버는 4173 포트입니다. 정적 파일만 열어도 보상 발급·관리자 접근 확인은 할 수 없으며 API 서버가 필요합니다.

서버 함수는 Vercel의 Node.js runtime, 기록 저장은 Upstash HTTPS REST API를 사용합니다.

- https://vercel.com/docs/functions/runtimes/node-js
- https://vercel.com/docs/project-configuration/vercel-json
- https://upstash.com/docs/redis/features/restapi
