# UAZ 품질 업데이트 (rules v6)

## 구현

- 기존 클릭/터치 목적지 지정과 후진 버튼 유지. 140 units/s² 가속, 감속 240, 전후진 전환 제동 350. 고속 조향 제한, 횡방향 관성, 차체 롤, 22% 벽 반동.
- 지연 추적 + 실제 속도 방향 look-ahead, 최대 12% 줌아웃. 총탄은 짧고 약하게, 충돌은 강하게, 포격은 거리 감쇠 흔들림. 카메라를 포함한 역투영으로 클릭 위치 일치.
- 16방향 UAZ WebP 스프라이트. 먼지/풀, 타이어 자국, 피격 불꽃, 50% 이하 연기, 20% 이하 검은 연기와 불꽃, 충돌 파편.
- 절차적으로 합성한 시동, 공회전/저속/고RPM 엔진, 감속, 흙길, 충돌, 피격, 스침, 보급, 블루존, 포탄/폭발, 탈출 연막/성공 효과음. 엔진 레이어 crossfade와 playbackRate 적용. 첫 시작 클릭으로 오디오 활성화, 소리 끄기 및 탭 숨김 시 음소거/중단.
- 방향 피격 표시로 전체 빨간 테두리 대체. 트레이서, 탄착 먼지, 폭발 연기, 블루존 전기/접근 노이즈, 가장자리 이전 프레임 기반 약한 모션블러.
- 전신주, 돌담, 논, 폐차, 창고, 가드레일, 표지판, 풀숲, 드럼통, 컨테이너. seed에 따른 재현 가능한 배치. 주요 도로/스폰/보급/탈출 주변은 확보. 논과 풀숲은 통과 가능, 나머지는 충돌 처리.
- WebP manifest의 실제 수신 바이트와 디코딩 완료를 반영하는 프리로드, 재시도 화면. 파티클 360개, 타이어 자국 240개 상한.
- 물리 변경에 따라 서버와 브라우저의 공유 엔진 및 버전을 함께 갱신. 점수/보상 계산, 개인 링크와 관리자 접근 규칙은 유지.

## 배경음 포함

공식 배틀그라운드 사운드트랙 페이지에서 메인 타이틀 `The First Survivor (Early Access Main Title)`의 MP3를 확보했습니다.

- 공식 페이지: https://www.pubg.com/en/media?category=sound_track
- 공식 음원: https://wstatic-prod-boc.krafton.com/PUBG_OFFICIAL/20230409/iPlz0aTH/The-First-Survivor_Early-Access-Main-Title.mp3
- 게임 파일: `public/assets/audio/pubg-main-theme.mp3`
- 전체 길이 약 3분 10초. 용량 절감을 위해 96 kbps stereo / 44.1 kHz MP3로 변환.
- `public/audio-config.mjs`에서 기본 활성화. 음량 6%, 반복 재생, 게임 종료/탭 숨김/소리 끄기에 맞춰 중단 또는 음소거.
- 매 프레임 재생 요청을 반복하지 않고 재생 상태가 바뀔 때만 요청.

효과음은 실제 UAZ 녹음 또는 PUBG에서 추출한 파일이 아닌 자체 합성음입니다.

## 검증

`npm run build && npm test`

19개 테스트: 서버 재현/보상 서명, 버전 불일치/위변조/빠른 제출 거부, 가속/제동/후진, 고속 회전, 충돌 반동, seed 40개 맵의 도로와 목적지 여유 공간, 피격 방향 및 스침 이벤트.
기존 테스트에서 현재 버전과 불일치했던 고정 탈출 좌표/체력 회복/규칙 버전 누락을 현재 명세로 갱신했습니다.

실제 게임 Canvas 코드로 자산 로드, 16프레임, 카메라 좌표 왕복, 주행/후진, 저체력/블루존/포격/새 맵/모바일 크기 렌더링을 확인했습니다. 작업 환경에 브라우저 실행 파일이 없고 설치 다운로드가 정상 파일을 반환하지 않아 실제 Chromium 브라우저 및 실기기에서의 음질/체감 조작 확인은 완료하지 못했습니다.

## 그래픽 소스

기존 PNG 원본은 보존하고 게임에서는 WebP만 요청합니다. `scripts/optimize-assets.mjs`는 `sharp`가 설치된 개발 환경에서 실행하는 선택적 재생성 도구이며 Vercel 빌드에는 필요하지 않습니다. `scripts/pack-countryside.cjs`는 생성된 10개 오브젝트의 알파 영역을 분리해 일정한 셀에 배치합니다.

새 이미지: built-in ImageGen으로 제작한 `public/assets/uaz16.png`, `public/assets/countryside.png`. 차량은 불규칙한 여백을 명시적 프레임 좌표로 읽어 범퍼 잘림을 방지합니다.

제작 프롬프트 요지: 올리브색 캔버스 지붕 UAZ-469 한 차량의 360도 회전, 고정 30도 내려다보는 카메라, 4×4의 16방향, 오른쪽부터 시계 방향, 실제 투명 배경, 낡은 군용 재질, 글자 없음. 맵은 같은 시점의 한국 시골풍 전신주·돌담·논·폐차·작은 창고·가드레일·화살표 표지판·풀숲·드럼통·컨테이너 10종을 각기 분리한 투명 아틀라스.
